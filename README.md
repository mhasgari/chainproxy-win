# chainproxy — زنجیره‌ی دو ساپسکریپشن (کاربر → A → B → اینترنت)

**شروع سریع:** [راهنمای سریع](docs/QUICKSTART.md) · **مستندات کامل:** [راهنمای کاربر](docs/USER-GUIDE.md) · [راهنمای توسعه‌دهنده](docs/DEVELOPER.md) · [محیط توسعه و تست روی VM](dev/README.md)


## شروع (یک کلیک)
ساده‌ترین راه: `ChainProxy-Setup-<نسخه>.exe` از [Releases](https://github.com/mhasgari/chainproxy-win/releases) (بدون ادمین؛ امضای دیجیتال ندارد و SmartScreen هشدار می‌دهد). یا zip را باز کنید و:
`Run.bat` را اجرا کنید. اولین بار خودش هر چه لازم باشد می‌گیرد و نصب می‌کند:
- **Python** (با tkinter) اگر نباشد: نصب‌کننده رسمی python.org، با بررسی امضای دیجیتال، برای کاربر جاری و بدون نیاز به ادمین
- **sing-box**: آخرین نسخه از GitHub، با بررسی sha256 و تلاش مجدد؛ اگر خراب یا ناقص بود خودکار دوباره نصب می‌شود
همان اولین بار یک میانبر «Chain Proxy» روی دسکتاپ و در Start Menu ساخته می‌شود؛ از آن به بعد فقط با آن میانبر کار کنید (هر بار وجود Python و sing-box را هم بررسی و در صورت نیاز ترمیم می‌کند). اگر میانبر را عمداً پاک کنید دوباره ساخته نمی‌شود؛ `Run.bat shortcut` آن را دوباره می‌سازد. اگر پوشه را جابه‌جا کنید، اجرای بعدی مقصد میانبر را اصلاح می‌کند.
سپس پنجره باز می‌شود. بار اول پنجره‌ی Settings برای وارد کردن لینک اول باز می‌شود (لینک دوم به‌طور پیش‌فرض لیست عمومی best از [GeminiRoute](https://github.com/alizn7/GeminiRoute) است) (یا `subs.txt` را ویرایش کنید؛ اگر نباشد از `subs.example.txt` ساخته می‌شود و هیچ‌وقت در گیت نمی‌رود).
`Run.bat cli` نسخه‌ی کنسولی را اجرا می‌کند.

اگر دانلود در شبکه‌ی شما مسدود بود، فایل‌ها را در پوشه‌ی `offline` بگذارید (راهنما: `offline\README.txt`).

## استفاده
- پنجره: Enable/Disable، Next/Prev، Rescan، دابل‌کلیک روی هر مسیر، نمایش IP و کشور خروجی، Settings.
- کنسول: `n` بعدی | `p` قبلی | `s` وضعیت | `l` فهرست | `r` تست مجدد | `q` غیرفعال‌سازی
- `next.bat` و `stop.bat` همزمان با پنجره هم کار می‌کنند.
- غیرفعال‌سازی یا بستن پنجره، تنظیمات قبلی پروکسی ویندوز را برمی‌گرداند.

## ترتیب انتخاب
زنجیره‌های A→B (به ترتیب تاخیر) ← فقط B ← فقط A (با `rank_by_speed` ترتیب کاملاً سرعتی). هر مسیر پیش از فعال‌شدن بررسی می‌شود:
کشور IP خروجی در `blocked_countries` نباشد (با سرویس‌های جایگزین اگر ipinfo جواب ندهد) و همه‌ی `strict_urls` (حتی بدون `https://`) پاسخ زیر ۴۰۰ بدهند.

## اطمینان‌پذیری
- هر نود پیش از استفاده با `sing-box check` اعتبارسنجی می‌شود؛ نودِ ناسازگار کل برنامه را از کار نمی‌اندازد.
- کانفیگ ابتدا با قالب جدید ساخته می‌شود و اگر هسته‌ی نصب‌شده قدیمی بود، خودکار قالب ساده‌تر امتحان می‌شود.
- اگر sing-box ناگهان بسته شود، ظرف چند ثانیه خودکار دوباره اجرا و روی همان مسیر برمی‌گردد؛ اگر مدام کرش کند، برنامه غیرفعال و پروکسی ویندوز برگردانده می‌شود.
- اگر مسیر فعال قطع شود، ناظر به مسیر مناسب بعدی می‌رود.
- اگر برنامه کرش کند یا kill شود: sing-box همراه آن می‌میرد (Job Object) و یک نگهبان کوچک پروکسی ویندوز را برمی‌گرداند؛ در خاموشی ناگهانی، اجرای بعدی (یا `stop.bat`) آن را بازیابی می‌کند.
- اگر دانلود ساپسکریپشن شکست بخورد، از آخرین نسخه‌ی ذخیره‌شده (`cache`) استفاده می‌شود.
- پورت‌های اشغال‌شده قبل از شروع تشخیص داده می‌شوند و پیام روشن می‌دهند (پورت‌ها در `config.json` قابل تغییرند).

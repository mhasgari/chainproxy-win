Offline / blocked-download fallback
-----------------------------------
Run.bat prefers files in this folder over downloading:

  python-3.12.10-amd64.exe   official installer from https://www.python.org/downloads/windows/
                             (its digital signature is verified before it runs)
  sing-box-<ver>-windows-amd64.zip
                             from https://github.com/SagerNet/sing-box/releases

Copy them here (from another machine or a mirror) and run Run.bat again.

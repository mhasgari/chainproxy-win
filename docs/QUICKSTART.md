# راهنمای سریع — Chain Proxy

یک صفحه برای شروع. جزئیات کامل در [راهنمای کاربر](USER-GUIDE.md).

## ۱. نصب (یک‌بار)
**روش آسان: نصب‌کننده.** فایل `ChainProxy-Setup-<نسخه>.exe` را از صفحه‌ی [Releases](https://github.com/mhasgari/chainproxy-win/releases) بگیرید و اجرا کنید (بدون نیاز به ادمین؛ نصب در `%LOCALAPPDATA%\Programs\ChainProxy`). چون امضای دیجیتال ندارد، ویندوز ممکن است هشدار SmartScreen بدهد: «More info» ← «Run anyway». در پایان «Start Chain Proxy now» را بزنید و از مرحله‌ی ۳ ادامه دهید. اگر دانلود در شبکه‌ی شما مسدود است، نسخه‌ی **`ChainProxy-Setup-Full-<نسخه>.exe`** (حدود ۶۰ مگابایت) را بگیرید؛ Python و sing-box داخل آن است و هیچ دانلود دیگری لازم نیست. حذف: Settings ← Apps (پروکسی ویندوز خودکار برمی‌گردد).

**روش دستی (zip):**
1. پوشه‌ی `chainproxy` را در یک جای ثابت بگذارید (مثلاً `C:\Tools\chainproxy`)، نه داخل زیپ یا Downloads.
2. روی **`Run.bat`** دوبل‌کلیک کنید. اولین بار خودش Python و sing-box را می‌گیرد (چند دقیقه) و یک میانبر **Chain Proxy** روی دسکتاپ می‌سازد.
3. پنجره‌ی **Settings** باز می‌شود: لینک ساپسکریپشن خودتان را در «Subscription 1» بگذارید و **Save** بزنید. «Subscription 2» به‌طور پیش‌فرض لیست عمومی **best** پروژه‌ی [GeminiRoute](https://github.com/alizn7/GeminiRoute) است (`https://alizn7.github.io/GeminiRoute/sub/best.txt`)؛ می‌توانید همان را نگه دارید یا لینک دیگری بگذارید.

> اگر Python از قبل روی سیستم باشد، همان استفاده می‌شود و Python دومی نصب نمی‌شود.

> دانلود مسدود است؟ فایل‌های Python و sing-box را در پوشه‌ی `offline` بگذارید (راهنما: `offline\README.txt`).

## ۲. استفاده‌ی روزانه
1. از میانبر دسکتاپ برنامه را باز کنید و **Enable** بزنید. بعد از چند ثانیه وضعیت **Active** (سبز) می‌شود و کروم از پروکسی استفاده می‌کند.
2. بالای پنجره مسیر فعلی و IP/کشور خروجی را می‌بینید. در فهرست، مسیر فعلی با `>` و رنگ سبز مشخص است.
3. سایت یا سرویسی کار نکرد؟ **Next route >** را بزنید، یا روی یک مسیر دیگر در فهرست **دابل‌کلیک** کنید.
4. کار تمام شد؟ **Disable** بزنید (یا پنجره را ببندید). پروکسی ویندوز به حالت قبل برمی‌گردد.

| دکمه | کار |
|---|---|
| Enable / Disable | روشن و خاموش کردن |
| Next route > / < Prev | مسیر مناسب بعدی / قبلی |
| Rescan | سنجش دوباره‌ی همه‌ی مسیرها |
| Settings | لینک‌ها، سایت‌های سخت‌گیر، کشورهای ممنوع |

## ۳. تنظیمات مفید (Settings)
- **Strict sites:** آدرس سرویسی که برایتان مهم است، هر خط یکی. فقط نام سایت کافی است (مثلاً `gemini.google.com`؛ `https://` خودکار اضافه می‌شود و فقط برای `http://` باید آن را بنویسید). فقط مسیرهایی فعال می‌شوند که به آن‌ها برسند.
- **Blocked exit countries:** کشورهایی که IP خروجی نباید در آن‌ها باشد (پیش‌فرض `IR`).
- **Direct suffixes:** دامنه‌هایی که مستقیم (بدون پروکسی) باز شوند (پیش‌فرض `.ir`).

## ۴. اگر مشکل پیش آمد
| نشانه | کار |
|---|---|
| اینترنت بعد از بسته‌شدن ناگهانی کار نمی‌کند | برنامه را دوباره باز کنید (خودش تنظیمات را برمی‌گرداند) یا `stop.bat` را اجرا کنید. |
| `no route passed verification` | Strict sites یا کشورهای ممنوع را سبک‌تر کنید، یا Rescan بزنید. |
| `port 10808 ... already in use` | برنامه‌ی دیگری آن پورت را دارد؛ آن را ببندید یا `mixed_port` را در `config.json` عوض کنید. |
| `subs.txt has no real subscription links` | لینک‌ها را در Settings بگذارید. |

لاگ‌ها: کادر پایین پنجره و فایل `runtime\core.log`.

## ۵. از خط فرمان
- `next.bat` — مسیر بعدی (هم‌زمان با پنجره کار می‌کند)
- `stop.bat` — غیرفعال‌سازی و برگرداندن پروکسی ویندوز
- `Run.bat cli` — نسخه‌ی کنسولی

## ۶. نکات امنیتی
- لینک‌های ساپسکریپشن شما در `subs.txt` است. این فایل را برای کسی نفرستید و در گیت قرار ندهید.
- پوشه‌های `cache` و `runtime` شامل رمز نودها هستند.
- ابزار kill switch ندارد: بعد از Disable یا بسته‌شدن، ترافیک مستقیم و با IP واقعی شما می‌رود.

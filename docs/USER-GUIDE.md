# راهنمای کاربر — Chain Proxy

> خلاصه‌ی یک‌صفحه‌ای: [راهنمای سریع](QUICKSTART.md)

این ابزار چند منبع پروکسی (موتور **Lantern**، ساپسکریپشن‌ها و پروفایل‌های v2ray) را به هم زنجیر می‌کند، بهترین مسیر را خودکار پیدا می‌کند و پروکسی ویندوز را روی آن تنظیم می‌کند تا کروم (و هر برنامه‌ای که از پروکسی سیستم استفاده می‌کند) از آن مسیر عبور کند. اگر مسیر برای سرویس موردنظر شما مناسب نبود، با یک کلیک مسیر مناسب بعدی انتخاب می‌شود.

---

## ۱. ایده در یک نگاه

ابزار دو «هاپ» دارد و برای هر هاپ چند منبع، **به‌ترتیب اولویت**:

| هاپ | اولویت ۱ | اولویت ۲ | اولویت ۳ |
|---|---|---|---|
| **هاپ اول (A)** | **Lantern** (پلن رایگان، بهترین سرور خودکار) | لینک ساپسکریپشن | پروفایل‌های v2ray (لینک‌های معمول `vless://` و …) |
| **هاپ آخر (B)** | لینک ساپسکریپشن (پیش‌فرض: لیست best از GeminiRoute) | پروفایل‌های v2ray | — |

از هر منبع چند نودِ سریع‌تر برگزیده و این‌طور وصل می‌شوند:

```
مرورگر شما  ──►  هاپ اول (A)  ──►  هاپ آخر (B)  ──►  اینترنت
```

- **IP خروجی** شما همان IP هاپ آخر (B) است.
- ترتیب مسیرها: اول زنجیره‌های A→B؛ داخل آن‌ها ابتدا منبع هاپ اول (Lantern، بعد ساپسکریپشن، بعد پروفایل)، بعد منبع هاپ آخر، بعد تاخیر. اگر زنجیره‌ی سالمی نبود به‌ترتیب **فقط B** و **فقط A** امتحان می‌شود. ستون «Source» در فهرست منبع هر مسیر را نشان می‌دهد؛ «Next» به مسیر مناسب بعدی می‌رود.
- ستون **Source** منبع هر مسیر را نشان می‌دهد. مسیری که هنگام انتخاب یا چرخش رد شود به رنگ نارنجی درمی‌آید و ستون **Status** دلیلش را می‌گوید (مثلاً `gemini: no answer` یا `Google sees exit in IR`). مسیرِ فقط Lantern معمولاً آخر جدول است و فقط وقتی به درد می‌خورد که هیچ زنجیره‌ی سالمی نباشد.
- منبعی که کار نکند (مثلاً Lantern بالا نیاید) فقط در لاگ گزارش می‌شود و بقیه ادامه می‌دهند.

> تاخیر فقط سرعتِ پاسخ را می‌سنجد، نه پهنای باند. مسیر با تاخیر کم لزوماً پرسرعت‌ترین نیست.

## ۲. پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- اینترنت (برای دانلود Python و sing-box در اولین اجرا، ساپسکریپشن‌ها و موتور Lantern حدود ۲۴ مگابایت در اولین استفاده؛ نسخه‌ی Full نصب‌کننده همه را دارد)
- هیچ لینکی لازم نیست: Lantern به‌علاوه‌ی لیست best پیش‌فرض هاپ آخر از همان لحظه‌ی اول کار می‌کند. لینک‌های خودتان (vless / vmess / trojan / shadowsocks / hysteria2) را اختیاری اضافه کنید.

Python و sing-box را لازم نیست خودتان نصب کنید؛ `Run.bat` در صورت نبودن، آن‌ها را می‌گیرد.

**اگر Python از قبل نصب باشد:** نصب‌کننده به آن دست نمی‌زند و برنامه همان را به کار می‌برد (نسخه‌ی ۳.۹ به بالا با tkinter؛ از `py -3`، `python` یا `%LOCALAPPDATA%\Programs\Python` پیدا می‌شود). فقط اگر Python نباشد، قدیمی باشد یا tkinter نداشته باشد، Python 3.12.10 برای کاربر جاری (بدون ادمین) نصب می‌شود؛ اگر همان نسخه‌ی ۳.۱۲.۱۰ بدون tkinter باشد، tkinter به آن اضافه می‌شود. حذف Chain Proxy هیچ Python‌ای را پاک نمی‌کند.

## ۳. نصب و اولین اجرا

**با نصب‌کننده (ساده‌ترین):** `ChainProxy-Setup-<نسخه>.exe` از صفحهٔ Releases پروژه را اجرا کنید؛ بدون ادمین در `%LOCALAPPDATA%\Programs\ChainProxy` نصب می‌شود، میانبر Start Menu (و در صورت انتخاب، دسکتاپ) می‌سازد و حذف‌کننده دارد که پروکسی ویندوز را هم برمی‌گرداند. نصب روی نسخه‌ی قبلی، `subs.txt` و `config.json` شما را نگه می‌دارد. نصب‌کننده امضای دیجیتال ندارد؛ SmartScreen هشدار می‌دهد (More info ← Run anyway). Python و sing-box داخل آن نیستند و در اولین اجرا همان‌طور که پایین‌تر آمده گرفته می‌شوند. **نسخه‌ی Full** (`ChainProxy-Setup-Full-<نسخه>.exe`، حدود ۶۰ مگابایت) Python و sing-box را هم دارد (در پوشه‌ی `offline`؛ مجوزها در `THIRD-PARTY-NOTICES.txt`) و برای شبکه‌هایی است که دانلود در آن‌ها مسدود است؛ این دو بدون دانلود نصب می‌شوند. بقیه‌ی این بخش برای نصب دستی از zip است.

1. پوشه‌ی `chainproxy` را در **یک جای ثابت** بگذارید (مثلاً `C:\Tools\chainproxy` یا داخل Documents). از اجرا از داخل فایل زیپ یا پوشه‌ی Downloads پرهیز کنید، چون میانبر به همین پوشه اشاره می‌کند.
2. روی `Run.bat` دوبل‌کلیک کنید.
3. اگر Python نصب نباشد، نصب‌کننده رسمی از python.org گرفته می‌شود، امضای دیجیتالش بررسی می‌شود و برای کاربر جاری (بدون نیاز به ادمین) نصب می‌شود.
4. sing-box (موتور اتصال) گرفته و با چک‌سام تأیید می‌شود.
5. یک میانبر **Chain Proxy** روی دسکتاپ و در Start Menu ساخته می‌شود.
6. پنجره‌ی برنامه باز می‌شود و چون هنوز لینک‌ها را نداده‌اید، پنجره‌ی **Settings** باز می‌شود. لینک اول را در «Subscription 1» و لینک دوم را در «Subscription 2» بگذارید و Save بزنید.

از این به بعد فقط با میانبر دسکتاپ کار کنید.

### اگر دانلود در شبکه‌ی شما مسدود است
فایل‌های زیر را از جای دیگری تهیه کنید و در پوشه‌ی `offline` بگذارید؛ `Run.bat` ابتدا از آن‌ها استفاده می‌کند:

| فایل | از کجا |
|---|---|
| `python-3.12.10-amd64.exe` | https://www.python.org/downloads/windows/ |
| `sing-box-<نسخه>-windows-amd64.zip` | https://github.com/SagerNet/sing-box/releases |

فایل `subs.txt` لینک‌های شماست و در گیت/انتشار نمی‌رود؛ اگر نباشد، از روی `subs.example.txt` ساخته می‌شود. لینک ساپسکریپشن هم اگر مستقیم باز نمی‌شود، می‌توانید به‌جای آن در `subs.txt` یک فایل محلی (مسیر کامل) یا لینک تکی نود (مثلاً `vless://...`) بگذارید.

## ۴. کار با پنجره

| بخش | کار |
|---|---|
| **Enable / Disable** | فعال‌سازی: راه‌اندازی Lantern، دانلود ساپسکریپشن‌ها، تست مسیرها، انتخاب بهترین مسیر و تنظیم پروکسی ویندوز. غیرفعال‌سازی: برگرداندن تنظیمات قبلی پروکسی و توقف اتصال. |
| **Next route > / < Prev** | رفتن به مسیر مناسب بعدی/قبلی. هر مسیر قبل از فعال‌شدن بررسی می‌شود (بخش ۶)؛ مسیری که رد شود رد می‌شود و مسیر بعدی امتحان می‌شود. |
| **Rescan** | سنجش دوباره‌ی همه‌ی مسیرها (وقتی شرایط شبکه عوض شده). |
| **فهرست مسیرها** | همه‌ی مسیرهای سالم با ستون‌های شماره، تاخیر، مسیر و منبع. مسیر فعلی با `>` و رنگ سبز مشخص است. **دابل‌کلیک** (یا Enter) روی یک مسیر، مستقیم به آن می‌رود. ترتیب: اول زنجیره‌های A→B، بعد فقط B، بعد فقط A؛ داخل هر گروه اول اولویت منبع، بعد تاخیر (با `"rank_by_speed": true` در `config.json` ترتیب کاملاً سرعتی می‌شود). ایموجی/پرچم‌های نام نودها در پنجره نمایش داده نمی‌شوند. |
| **وضعیت** (بالای پنجره) | نشانگر متنی `● Active` (سبز) / `● Disabled` (خاکستری) / `● Starting` (نارنجی)؛ این فقط نشانگر است، دکمه نیست (دکمهٔ Enable/Disable کنار آن است)، مسیر فعلی با تاخیرش، IP و کشور خروجی و وضعیت Lantern. |
| **کادر لاگ** | به‌صورت پیش‌فرض بسته است؛ با زدن روی عنوان `▸ Log` باز می‌شود (و با `▾ Log` دوباره بسته). گزارش کارهای انجام‌شده و خطاها؛ دکمه‌های Copy و Clear فقط وقتی باز است دیده می‌شوند. |
| **Settings** | تنظیمات (بخش ۵). |

**بستن پنجره با ضربدر، برنامه را نمی‌بندد:** در ناحیه‌ی اعلان‌ها کنار ساعت می‌ماند و اتصال ادامه دارد (بار اول یک پیام نشان می‌دهد). روی آیکون **دابل‌کلیک** کنید تا پنجره برگردد، یا **راست‌کلیک** کنید: Open، Enable/Disable، Next route، Check for updates و **Exit**. فقط **Exit** برنامه را کاملاً می‌بندد، پروکسی ویندوز را برمی‌گرداند و Lantern را متوقف می‌کند. (اگر آیکون را نمی‌بینید، در Windows 11 از فلش «^» کنار ساعت آن را بیرون بکشید.) خروج از ویندوز (Logoff/Shutdown) هم پروکسی را برمی‌گرداند. این رفتار در Settings ← General قابل خاموش‌شدن است. باز کردن دوباره‌ی میانبر، پنجره‌ی موجود را نشان می‌دهد و نمونه‌ی دوم نمی‌سازد.

**به‌روزرسانی خودکار:** برنامه هر چند ساعت یک‌بار آخرین release را در GitHub می‌بیند. در نسخه‌ی نصب‌شده با نصب‌کننده، نسخه‌ی جدید به‌طور پیش‌فرض خودکار دانلود، با sha256 اعلام‌شده‌ی GitHub راستی‌آزمایی، بی‌صدا نصب و برنامه دوباره باز می‌شود (اگر فعال بودید دوباره Enable می‌شود؛ لینک‌ها و تنظیمات شما می‌مانند). در نسخه‌ی portable (zip) فقط خبر می‌دهد و پیوند دانلود می‌دهد. خاموش‌کردن: Settings ← General ← Install new versions automatically. بررسی دستی: همان‌جا یا منوی آیکون ← Check for updates. نصب‌کننده‌ها امضای دیجیتال ندارند.

**اگر برنامه ناگهانی بسته شود** (End Task در Task Manager، کرش): هسته‌ی sing-box هم همراه آن بسته می‌شود و یک فرایند نگهبان کوچک تنظیمات پروکسی ویندوز را به حالت اول برمی‌گرداند. اگر کامپیوتر ناگهان خاموش شد یا از ویندوز خارج شدید، با بازکردن دوباره‌ی برنامه (یا `stop.bat`) تنظیمات برمی‌گردد.

### حالت کنسولی
`Run.bat cli` همان کار را در پنجره‌ی کنسول انجام می‌دهد. کلیدها: `n` بعدی، `p` قبلی، `s` وضعیت، `l` فهرست، `r` تست مجدد، `q` غیرفعال‌سازی.

### فایل‌های میانبر
- `next.bat` — بدون باز کردن پنجره، مسیر بعدی را انتخاب می‌کند (اگر برنامه در حال اجرا باشد). می‌توانید برایش میانبر کیبورد بگذارید.
- `stop.bat` — برنامه را غیرفعال می‌کند و پروکسی ویندوز را برمی‌گرداند. اگر برنامه کرش کرده و اینترنت شما به پروکسی مرده وصل مانده، همین فایل را اجرا کنید.
- `quit.bat` — مثل `stop.bat` و علاوه بر آن پنجره‌ای را که در ناحیه‌ی اعلان‌هاست هم می‌بندد (نصب‌کننده و حذف‌کننده از آن استفاده می‌کنند).

## ۵. تنظیمات (Settings)

پنجره‌ی Settings چهار زبانه دارد.

### Sources — منابع به‌ترتیب اولویت
| گزینه | معنی |
|---|---|
| **هاپ اول ۱: Lantern** | موتور headless پروژه‌ی Lantern با پلن رایگان؛ بهترین سرور را خودش انتخاب می‌کند. تیک پیش‌فرض روشن است. بار اول موتور (حدود ۲۴ مگابایت، با sha256 ثابت) دانلود و راستی‌آزمایی می‌شود؛ نسخه‌ی Full نصب‌کننده آن را دارد. |
| **هاپ اول ۲: Subscription link** | لینک ساپسکریپشن اول (خط اول `subs.txt`). |
| **هاپ اول ۳: v2ray profiles** | لینک‌های معمول v2ray، هر خط یکی (`vless://` `vmess://` `trojan://` `ss://` `hysteria2://`)؛ در فایل `profiles_first.txt`. کمترین اولویت. |
| **هاپ آخر ۱: Subscription link** | لینک ساپسکریپشن دوم (خط دوم `subs.txt`؛ IP خروجی از این است). پیش‌فرض: لیست عمومی **best** پروژه‌ی [GeminiRoute](https://github.com/alizn7/GeminiRoute) (`https://alizn7.github.io/GeminiRoute/sub/best.txt`، هر ساعت بازسازی می‌شود)؛ اگر best خالی شد از `.../sub/gemini.txt` یا `.../sub/all.txt` همان‌جا استفاده کنید. |
| **هاپ آخر ۲: v2ray profiles** | لینک‌های معمول v2ray برای هاپ آخر، هر خط یکی؛ در `profiles_exit.txt`. اولویت دوم. |

حداقل یک منبع لازم است. منبع پایین‌تر جایگزین منبع‌های بالاتر است نه جایگزین‌شونده. فایل‌های `subs.txt` و `profiles_*.txt` اطلاعات شخصی‌اند و در گیت یا بسته‌ی انتشار نمی‌روند.

### Filters
| گزینه | معنی |
|---|---|
| **Strict sites** | هر خط یک آدرس. **پیش‌فرض: `https://gemini.google.com`.** نوشتن فقط نام سایت کافی است (`https://` خودکار اضافه می‌شود؛ فقط برای `http://` باید بنویسید). مسیری فعال می‌شود که به همه‌ی این آدرس‌ها وصل شود و پاسخ زیر ۴۰۰ بگیرد؛ خالی = بدون شرط. توجه: فقط «پاسخ زیر ۴۰۰» بررسی می‌شود، نه اینکه سرویس برای آن کشور واقعاً باز باشد. برای `gemini.google.com` علاوه بر پاسخ سایت، کشوری که خود Google برای IP خروجی می‌بیند هم خوانده می‌شود؛ اگر یکی از «کشورهای ممنوع» (مثلاً IR) باشد، مسیر رد می‌شود (آن مسیر صفحه‌ی «Gemini در موقعیت شما در دسترس نیست» را نشان می‌دهد). |
| **Blocked exit countries** | کدهای کشور (با کاما) که IP خروجی نباید در آن‌ها باشد. پیش‌فرض: `IR`. |
| **Direct suffixes** | پسوند دامنه‌هایی که بدون پروکسی و مستقیم باز شوند. پیش‌فرض: `.ir`. |

### General
- **Keep running in the notification area when the window is closed** (پیش‌فرض روشن).
- **Install new versions automatically** (پیش‌فرض روشن) و دکمه‌ی **Check for updates now**.

### About
نسخه، مجوز و اشاره به Lantern و sing-box.

منابع و Direct suffixes از **Enable بعدی** اعمال می‌شوند؛ Strict sites و کشورهای ممنوع **فوراً**.

تنظیمات پیشرفته‌تر (پورت‌ها، تعداد نود آزمایشی، زمان‌ها و …) در فایل `config.json` است؛ فهرست کامل در [راهنمای توسعه‌دهنده](DEVELOPER.md#۸-مرجع-تنظیمات-configjson).

## ۶. سناریوهای رایج

**سرویسی که می‌خواهم IP من را رد می‌کند.**
۱) در پنجره `Next route` را بزنید تا مسیر بعدی (با IP خروجی دیگر) انتخاب شود و دوباره امتحان کنید.
۲) اگر همیشه همان سرویس مشکل دارد، آدرسش را در **Strict sites** بگذارید تا ابزار خودش مسیرهای ناسازگار را رد کند.

**IP خروجی در کشور دلخواه من نیست.**
از فهرست مسیرها چند مورد را با دابل‌کلیک امتحان کنید و در وضعیت، کشور خروجی را ببینید. (کشورهای ممنوع را هم می‌توانید در Settings تعریف کنید.)

**سایت‌های ایرانی کند شده‌اند یا باز نمی‌شوند.**
`.ir` به‌صورت پیش‌فرض مستقیم باز می‌شود. دامنه‌های دیگر (مثلاً `.com` ایرانی) را در **Direct suffixes** اضافه کنید.

**می‌خواهم موقتاً بدون پروکسی کار کنم.**
Disable را بزنید؛ هر وقت خواستید دوباره Enable کنید.

**اتصال وسط کار قطع شد.**
ناظر خودکار هر ۶۰ ثانیه مسیر را می‌سنجد و بعد از دو شکست پشت‌سرهم به مسیر مناسب بعدی می‌رود. اگر خود sing-box بسته شود، ظرف چند ثانیه دوباره اجرا می‌شود.

## ۷. عیب‌یابی

| پیام / نشانه | علت و راه‌حل |
|---|---|
| `no source configured` | Lantern خاموش است و هیچ لینک یا پروفایلی هم نیست. در Settings ← Sources یکی را فعال کنید. |
| `Lantern is not available (...)` | موتور بالا نیامد یا به سرور رایگان وصل نشد (دانلود موتور مسدود، پورت `lantern_port` اشغال، اینترنت قطع). بقیه‌ی منابع ادامه می‌دهند؛ لاگ و `runtime\lantern\log\lantern.log` را ببینید. نسخه‌ی Full موتور را از قبل دارد. |
| `cannot get sing-box: ...` | دانلود مسدود یا قطع است. فایل zip هسته را در پوشه‌ی `offline` بگذارید. |
| `port 42815 (mixed_port) is already in use` | برنامه‌ی دیگری (یا نسخه‌ی دیگر همین ابزار) آن پورت را دارد. آن را ببندید یا `mixed_port` را در `config.json` عوض کنید. |
| `already running` | یک نمونه از برنامه باز است. از همان استفاده کنید یا `stop.bat` را بزنید. |
| `no usable nodes in either subscription` | لینک‌ها دانلود نشدند یا فرمت پشتیبانی‌نشده دارند. خروجی لاگ و بخش «محدودیت‌ها» را ببینید. |
| `no route available` | هیچ مسیری تست تاخیر را رد نکرد (یا همه‌ی مسیرها با Strict sites / کشور ممنوع ناسازگار بودند). Settings را سبک‌تر کنید یا بعداً Rescan کنید. |
| `no route passed verification` | مسیرها هستند اما هیچ‌کدام بررسی نهایی را رد نکردند. Strict sites یا کشورهای ممنوع را بازبینی کنید. |
| `sing-box rejected the configuration` | نسخه‌ی هسته با یکی از نودها سازگار نیست. `runtime\core.log` را ببینید؛ `python chain.py install-core` هسته را به آخرین نسخه به‌روز می‌کند. |
| بعد از بسته‌شدن ناگهانی، اینترنت کار نمی‌کند | `stop.bat` را اجرا کنید (یا یک بار دیگر برنامه را اجرا و غیرفعال کنید). تنظیمات اصلی پروکسی برمی‌گردد. |
| در Strict sites آدرس نوشتم ولی `-> no answer` می‌دهد | آن سایت از آن مسیر جواب نمی‌دهد (یا مسدود است). آدرس بدون `https://` هم پذیرفته می‌شود. مسیر رد می‌شود و بعدی امتحان می‌شود. |
| `exit IP unknown` | سرویس‌های تشخیص IP (ipinfo.io و جایگزین‌ها) از آن خروجی جواب نداده‌اند. مسیر رد نمی‌شود، اما بررسی کشور ممنوع برای آن انجام نشده. |
| `[A] download failed (... CERTIFICATE_VERIFY_FAILED ... certificate has expired)` | Python گواهی سایت را نپذیرفته (معمولاً مخزن گواهی ویندوز قدیمی است یا ساعت/تاریخ کامپیوتر غلط است). از نسخه‌ی 1.2.2 برنامه خودکار با پشته‌ی TLS خود ویندوز (`curl.exe`) دوباره تلاش می‌کند و بررسی گواهی را غیرفعال نمی‌کند. اگر باز هم شکست خورد: تاریخ و ساعت کامپیوتر را درست کنید، Windows Update را اجرا کنید، یا محتوای ساپسکریپشن را در یک فایل ذخیره و مسیر کامل آن را در `subs.txt` بگذارید. |
| میانبر دسکتاپ کار نمی‌کند | پوشه جابه‌جا شده؛ `Run.bat` را از داخل پوشه‌ی جدید اجرا کنید تا میانبر خودکار اصلاح شود. |

فایل‌های مفید برای بررسی: `runtime\core.log` (گزارش sing-box) و کادر لاگ پنجره.

## ۸. حریم خصوصی و امنیت

- ابزار روی **خود ویندوز** اجرا می‌شود؛ هیچ سرور واسطه‌ای از ما در کار نیست. ترافیک شما فقط از نودهای ساپسکریپشن‌های خودتان عبور می‌کند.
- پورت‌های محلی (`42815`، `42816`، `42817`) فقط روی `127.0.0.1` باز هستند و از شبکه‌ی محلی در دسترس نیستند. با این حال برنامه‌های دیگر روی همین کامپیوتر می‌توانند به آن‌ها وصل شوند.
- پوشه‌های `cache` و `runtime` شامل اطلاعات نودها (از جمله رمزها و UUID) هستند. آن‌ها را جایی منتشر نکنید و پوشه را بدون پاک‌کردن آن‌ها برای کسی نفرستید.
- **Lantern:** موتور آن به سرورهای Lantern وصل می‌شود (پلن رایگان، مشمول شرایط استفاده‌ی خود Lantern) و داده‌ی خود را در `runtime\lantern` نگه می‌دارد. با خاموش‌کردن آن در Settings هیچ ارتباطی با Lantern برقرار نمی‌شود.
- **به‌روزرسانی:** برنامه برای دیدن نسخه‌ی جدید به `api.github.com` درخواست می‌زند (و بدون ارسال هیچ اطلاعات شخصی)؛ با خاموش‌کردن Auto update فقط دستی بررسی می‌شود.
- برای نمایش IP و کشور خروجی، ابزار از طریق مسیر انتخابی به `ipinfo.io` و در صورت شکست به `api.country.is` و `ipwho.is` درخواست می‌زند (قابل تغییر با `geo_url` و `geo_fallback_urls`؛ `geo_url` خالی = بدون این درخواست).
- Python از python.org و sing-box از GitHub (SagerNet/sing-box) گرفته می‌شود؛ نصب‌کننده‌ی Python پیش از اجرا با امضای دیجیتال و هسته با چک‌سام راستی‌آزمایی می‌شود.

## ۹. محدودیت‌ها

- **فقط پروکسی سیستم:** برنامه‌هایی که تنظیمات پروکسی ویندوز را نادیده می‌گیرند (برخی بازی‌ها، ابزارهای خط فرمان، بعضی برنامه‌ها) از مسیر عبور نمی‌کنند. کروم و Edge از آن استفاده می‌کنند؛ فایرفاکس بسته به تنظیماتش ممکن است نیاز به «Use system proxy settings» داشته باشد.
- **قطع‌کننده‌ی اضطراری (kill switch) ندارد:** ابزار ترافیک را در صورت قطع شدن مسیر مسدود نمی‌کند. وقتی غیرفعال می‌کنید (یا برنامه ببندد یا کرش کند)، پروکسی ویندوز برمی‌گردد و ترافیک **مستقیم و بدون پروکسی** می‌رود؛ پس IP واقعی شما نمایان می‌شود.
- **فرمت ساپسکریپشن:** فقط لینک‌های `vless://`، `vmess://`، `trojan://`، `ss://`، `hysteria2://` (و `hy2://`) در قالب متن ساده یا base64. فرمت Clash YAML یا JSON خود sing-box پشتیبانی نمی‌شود. شدوساکس با پلاگین (`plugin=`) رد می‌شود.
- **هاپ دوم با UDP:** نود hysteria2 (مبتنی بر UDP) معمولاً نمی‌تواند به‌عنوان هاپ دوم از داخل هاپ اول عبور کند؛ چنین ترکیبی در تست‌ها حذف می‌شود.
- **تشخیص کشور** به سرویس‌های ipinfo.io / api.country.is / ipwho.is وابسته است؛ اگر هیچ‌کدام از آن خروجی جواب ندهند، بررسی کشور انجام نمی‌شود (مسیر رد نمی‌شود، فقط IP «unknown» نمایش داده می‌شود).
- ابزار فقط ویندوز را هدف می‌گیرد (تنظیم پروکسی ویندوز و راه‌انداز). بخش‌های Python روی سیستم‌های دیگر برای توسعه و تست اجرا می‌شود اما پروکسی سیستم را تغییر نمی‌دهد.

## ۱۰. حذف کامل

1. Disable را بزنید (یا `stop.bat`) تا پروکسی ویندوز برگردد.
2. میانبر **Chain Proxy** را از دسکتاپ و از Start Menu پاک کنید.
3. پوشه‌ی `chainproxy` را پاک کنید. (Python نصب‌شده را می‌توانید از Settings → Apps حذف کنید؛ اگر برنامه‌ی دیگری از آن استفاده می‌کند، دست نزنید.)
